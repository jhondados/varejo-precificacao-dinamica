# 🛒 Precificação Dinâmica

> Precificação dinâmica de produtos com IA. Calcula o preço ótimo por SKU e canal considerando elasticidade, concorrência e estoque para maximizar margem.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/varejo-precificacao-dinamica/

## 📊 Resultados-chave (KPIs)
**+16%** Margem · **+12%** Receita · **monitor.** SKUs · **horário** Repricing

## 🧠 Tecnologias de IA
ML · Price Elasticity · Optimization

## ✨ O que faz
- Preço ótimo por SKU
- Elasticidade de demanda
- Monitor de concorrência
- Markdown inteligente
- Maximização de margem

## 🗄️ Fonte de dados real
[Mercado + concorrência](https://www.gov.br/mdic) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
